**INFRA-MONITOR**

A Python tool that checks whether selected hosts are reachable, records
response times and timestamps, and stores the results in SQLite.

## Status

Early development. Currently being built as part of a six-month
technical development plan.

## Planned features

- Check whether hosts respond (ping or HTTP)
- Record response time and timestamp for each check
- Store results in a SQLite database
- Later: a small FastAPI backend to view results
- Later: Docker, Terraform and a CI/CD pipeline
